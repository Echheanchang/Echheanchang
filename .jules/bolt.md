## 2024-03-24 - Tick Loop Invariants in Mineflayer
**Learning:** The `bot.on('time')` event in `mineflayer` runs 20 times per second (every game tick). Calculating invariants or changing state conditionally within this loop can be computationally wasteful over time. It is crucial to preserve the exact functional state transitions of random variables when optimizing this loop, as standard loop optimizations like moving variables outside the loop can easily break functionality (e.g. producing the same random value repeatedly instead of rerolling). Furthermore, changing single-execution code like startup config reading is a micro-optimization with zero measurable effect.
**Action:** Always inspect the frequency of event loops in bots. When hoisting logic out of tick loops, double-check that you are only hoisting constants (e.g., base intervals * 20), not variables meant to be randomized or recalculated per tick. Avoid optimizing startup code unless there's a demonstrable bottleneck.
