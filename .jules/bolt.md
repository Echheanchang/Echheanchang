## 2024-03-24 - High-Frequency Loop Optimization in Mineflayer
**Learning:** The `time` event in Mineflayer (`bot.on('time')`) is incredibly hot, firing 20 times per second (every single game tick). Operations that seem small, like `Math.random()` and basic arithmetic, add up significantly when run at this frequency, especially in bots meant to run 24/7. Additionally, re-calculating random interval targets every tick inside this loop not only wastes CPU cycles but also fundamentally changes the intended random distribution by constantly re-rolling the target.
**Action:** Always scrutinize any code inside `bot.on('time')` or similar high-frequency game loops. Pre-calculate values, hoist variables outside the loop, and ensure state changes (like selecting a random delay) only happen when necessary, not continuously on every tick.
